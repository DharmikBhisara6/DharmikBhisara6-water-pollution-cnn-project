# Source Files

## Overview

This project was implemented entirely using **Google Colab**.

All figures, tables, model outputs, and evaluation results were generated directly from the Jupyter Notebook using Python. No external software was used to create the figures or perform the analysis.

## Software and Libraries

The following libraries were used during implementation:

* TensorFlow / Keras
* Matplotlib
* NumPy
* Pandas
* Scikit-learn

## Source Code

The complete implementation, including data preprocessing, CNN model development, training, evaluation, and generation of figures and tables, is available in the **Codes** folder.

## Tables

Editable source tables used in the report are available in the **Tables** folder.

## Figures

The generated figures used in the report are available in the **Figures** folder.

## Development Environment

* Platform: Google Colab
* Programming Language: Python
