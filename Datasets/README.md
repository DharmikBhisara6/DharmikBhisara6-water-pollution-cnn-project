## Dataset

Dataset Name: Water Pollution Dataset

The dataset used in this project contains images of water bodies that were categorized into two classes:

* Clean
* Polluted

Image Size:

* 224 × 224 pixels

Dataset Split:

* Training Images: 234
* Validation Images: 58

Note:
The dataset file is not included in this repository due to file size limitations. Please place the dataset ZIP file (`training_vs_ideal_mapping.zip`) in the project directory before running the notebook.
