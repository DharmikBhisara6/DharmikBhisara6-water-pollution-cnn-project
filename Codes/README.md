# Water Pollution Classification Using CNN and Transfer Learning

## Project Overview

This project implements a Convolutional Neural Network (CNN) and MobileNetV2 transfer learning model for water pollution image classification. The objective is to classify water images into two categories: Clean and Polluted.

## Dataset

Dataset: Water Pollution Image Dataset

The dataset contains water-related images that were organized into two classes:

* Clean
* Polluted

## Methodology

The project includes:

1. Dataset loading and preprocessing
2. Image resizing to 224 × 224 pixels
3. Image normalization
4. Data augmentation
5. Training and validation split
6. CNN model development
7. Model evaluation using accuracy and loss
8. Confusion matrix generation
9. Classification report generation
10. Transfer learning using MobileNetV2
11. Performance comparison between CNN and MobileNetV2
